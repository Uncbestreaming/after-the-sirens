# After the Sirens

A standalone, choice-based zombie-apocalypse survival story.

## Run locally

Open `index.html` in a modern browser. The game uses browser speech synthesis for narration and local browser storage for saved games.

## Publish with GitHub Pages

1. Create a GitHub repository named `after-the-sirens` and upload `index.html` and this README to the repository root.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. GitHub Pages will provide a URL in the form `https://YOUR-USERNAME.github.io/after-the-sirens/`.

The game is self-contained; it does not require a build step or external assets.
